# OpenGL_Resources
A repository for practice material while learning OpenGL

Program can be run in VSCode using the 'Launch' button at the bottom of the window if all extensions are installed. Otherwise, the 'Makefile' in /build can be run (by typing 'make' in the terminal in the build folder) to compile the program, and then the program EXE (currently called 'test_opengl') can be run to launch the program.

NOTES:
- OpenGL is being run within C++ for the following programs.
- Currently only test in VSCode using C/Cpp, CMake, CMakeTools extensions, on Linux Ubuntu 24.04.4 OS -> GCC14+ compiler used in 'CMake: Configure' in VSCode CMake setup

- Graphics card specific versions of OpenGL required in many cases
